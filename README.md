# 🚀 70 Years of Global Space Missions — Data Analysis Dashboard

An end-to-end data analytics project analyzing 6,230+ global space missions from 1957–2025, covering launch trends, success/failure rates, cost efficiency, and the rise of private spaceflight — built using Excel/Power Query, SQL Server, and Power BI.

## 📊 Live Dashboard
[View interactive dashboard](https://app.powerbi.com/links/0Ss0rNBHLb?ctid=edc5c3bf-4ab5-4697-84fa-41b44eb08b5e&pbi_source=linkShare)

## 🛠️ Tech Stack
- **Excel / Power Query** — data cleaning, transformation, calculated columns
- **SQL Server (T-SQL)** — data analysis, aggregations, window functions, risk classification
- **Power BI** — interactive dashboard with slicers, dual-axis charts, drillthrough, and mobile layout

## 📁 Project Files
| File | Description |
|---|---|
| `space_missions_cleaned.csv` | Cleaned dataset (6,230 missions, 30 columns) |
| `SQLQuery1.sql` | 10 SQL queries covering success rates, cost trends, risk classification, and more |
| `Final project dashboard.pbix` | Power BI dashboard file |

## 🔍 Key Insights
- **93.85% overall mission success rate** across 70 years of global space missions
- **Reusable rockets cost ~44% less per kg of payload** ($86K vs $154K) compared to expendable rockets, validating the industry shift toward reusability
- Soviet Union had the lowest success rate (89.57%) among major spacefaring nations, reflecting the experimental nature of the early Space Race
- Clear generational shift from **government-dominated** to **private-sector-driven** launches in recent decades (SpaceX, Rocket Lab, Blue Origin)
- Built an **ABC risk classification system** for payload .

## 📈 Dashboard Features
- KPI summary cards (total missions, success rate, countries involved, operators)
- Interactive slicers (decade, country, payload size classification)
- Dual-axis cost analysis (sum vs average cost per decade)
- World map of launch sites
- Government vs Private launch trend over time
- Mobile-optimized layout
